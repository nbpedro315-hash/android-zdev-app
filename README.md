# snake-painel
Pacote pessoal de teste do Snake.io com painel visual

Este repositório contém um aplicativo Android simples que implementa um jogo estilo **Snake** usando um `SurfaceView` customizado.

- **Compilar APK**: use o workflow GitHub Actions `build-apk.yml` (release) ou `montar.yml` (debug).  
- **Desenvolvimento local**: abra o projeto no Android Studio e execute **Run > app**.

O código principal está em `app/src/main/java/com/example/snakepanel/Panel.java`.
